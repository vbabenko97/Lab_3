# Lab_3

## Overview
Small C++ console program that creates a square or circle based on user input and prints the resulting areas and center coordinates.

## Build
Use any C++17-compatible compiler. Example with `g++`:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic \
  main.cpp circle.cpp square.cpp geometrical_figure.cpp \
  -o lab3
```

## Run

```bash
./lab3
```
